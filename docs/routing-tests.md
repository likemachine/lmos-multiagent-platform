# Тестирование маршрутизации

Для каждого вопроса фиксируются:

- текст вопроса;
- ожидаемый агент;
- фактически выбранный агент;
- наличие ошибки классификатора;
- время ответа;
- оценка качества ответа.

## Известный наблюдаемый риск

LLM-классификатор на `llama3.2` может возвращать некорректный JSON,
например без обязательного поля `reason`. В этом случае Runtime
завершает подписку ошибкой до вызова агента.

Результаты сохраняются в `tests/results/`.
