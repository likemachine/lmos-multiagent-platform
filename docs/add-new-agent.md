# Добавление нового агента

1. Создать экземпляр `agent-runtime` с уникальным именем и портом.
2. Задать модель Ollama в переменных окружения.
3. Создать Deployment и Service.
4. Создать ресурс `Agent` с чётким описанием роли.
5. Включить возможность агента в `ChannelRouting`.
6. Проверить прямой вызов агента.
7. Отправить контрольный вопрос через Runtime.
8. Проверить `classified agent` и `Resolved agent` в логах Runtime.

Описание агента должно чётко отделять его роль от других агентов.
