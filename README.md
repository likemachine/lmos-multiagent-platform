# LMOS-based Multi-Agent Platform

Локальная мультиагентная платформа интеллектуальной поддержки,
построенная на Eclipse LMOS, Kubernetes, Ollama, Kotlin/ARC и MCP.

## Назначение

Проект исследует подключение специализированных LLM-агентов к LMOS,
их автоматическую маршрутизацию и работу с локальными моделями
без использования внешних облачных API.

## Технологии

- Eclipse LMOS — регистрация агентов, обнаружение, маршрутизация и оркестрация.
- Kubernetes / K3s — развёртывание сервисов.
- Ollama — локальное выполнение LLM и embedding-моделей.
- Kotlin / Eclipse ARC — универсальный агентный runtime.
- Model Context Protocol (MCP) — подключение агента к PostgreSQL.
- PostgreSQL — источник данных для агента-аналитика.

## Агенты

| Агент | Модель | Назначение |
|---|---|---|
| llama-agent | llama3.2 | Общие вопросы и генерация текстов |
| code-agent | qwen3.5:9b | Программирование, Bash, отладка |
| postgres-analyst | задаётся конфигурацией | Анализ данных PostgreSQL через MCP |

## Структура

```text
agent-runtime/       Универсальный Kotlin/ARC-дистрибутив
deploy/agents/       Конфигурации и YAML экземпляров агентов
deploy/lmos/         Конфигурация LMOS
docs/                Документация
scripts/             Клиент и вспомогательные скрипты
tests/               Вопросы и результаты маршрутизации
examples/            Примеры фактических LMOS-ресурсов
```

## Быстрый тест

```bash
python scripts/ask_lmos.py \
  "Write a Bash command to print the first five lines of a file."
```
## Важное замечание
LLM-классификатор может ошибаться при неоднозначных вопросах
или пересекающихся описаниях агентов. Такие случаи фиксируются
в  tests/results/  и анализируются отдельно.
